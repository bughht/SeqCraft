# Repository agent instructions

When creating or editing anything under `examples/`, follow the **Writing example notebooks**
section in [`examples/README.md`](examples/README.md).

Examples are user-facing teaching material, not pull-request or design records. Development
history, evidence arguments and architecture rationale belong in `CHANGELOG.md`, the pull request,
or `tools/module_mining/`.

`examples/README.md` is the single source for those rules; this file and `CLAUDE.md` only point at
it.
