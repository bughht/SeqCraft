# Direct dependencies that materially affect CI behavior.  Transitive dependencies remain
# resolver-managed unless they demonstrate a compatibility or reproducibility problem.
# NumPy is pinned per interpreter because its own support floor moves faster than ours.
# `requires-python` in pyproject.toml is >=3.10, and NumPy 2.3.0 raised its floor to >=3.11, so a
# single unconditional pin cannot install on the minimum Python we claim to support.  2.2.6 is the
# last release of the 2.2 line and the last NumPy supporting 3.10.
#
# Keep BOTH markers mutually exclusive and exhaustive when bumping either line.  Dropping the
# `python_version < "3.11"` row, or widening the other row's marker over it, silently uninstalls
# the 3.10 lane rather than failing it -- pip would resolve NumPy from the floor in pyproject.toml
# (numpy>=1.24) and CI would test a version nobody chose.
numpy==2.2.6; python_version < "3.11"
numpy==2.4.6; python_version >= "3.11"
